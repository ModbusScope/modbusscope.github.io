Unlimited has no artificial caps. Your hardware and network are the only limit. It is a one-time purchase, not a subscription.

Open core

The ModbusScope core is open source and developed on GitHub. Unlimited features are built on top of it. View the source.

Questions

What do I get with Free?

Up to 2 devices and 5 registers, with all core monitoring features. Anyone can use it, including at work, as long as you stay within these limits.

What happens when v5.1 is released?

Unlimited features require a paid license. Free stays available with its limits.

How much will Unlimited cost?

The price is not set yet. It will be announced before v5.1. Email us if you want to hear about it.

How do updates work?

For 12 months after purchase you get all updates. After that you can keep using the software indefinitely, limited to the latest licensed minor version. Updates within that minor version, including maintenance releases and bug fixes, remain available. Security fixes are only guaranteed for the latest software version.

Where can I read the license terms?

See the commercial adapter license terms. They apply to the commercial adapter and related proprietary components.

Is support for more protocols included?

Modbus is the current focus. Broader industrial protocol support is on the roadmap and will be added in future releases.
