Features

Real-time visibility for industrial monitoring and field data analysis.

~

Real-Time Visibility

Watch device data update live on an interactive graph and spot changes as they happen. Automatic scaling and smooth range updates help you focus on what matters in the moment.

IP

Modbus Today, More Protocols Ahead

Modbus is the current focus, with a roadmap that expands into additional industrial protocol coverage. The platform is designed to grow with your monitoring needs.

Nx

Multiple Devices

Examine more than one device in the same session, compare readings, and correlate signals from different points in a system or network.

f(x)

Custom Expressions

Build formulas to combine, scale, convert, and compare values. Create derived metrics, convert units, and model the signals that matter to your process.

min

Statistical Analysis

Drag markers across a time range and instantly calculate min, max, average, median, and slope. Zoom in on any interval and make decisions from evidence instead of guesswork.

CSV

CSV Export

Export recorded time series to CSV for analysis in Excel, Python, MATLAB, or any tool you already use. Keep timestamps and channel data together for downstream review.

reg

Signal Coverage

Work with the register and signal types you need today, with a monitoring workflow built to handle the broader industrial data picture as support expands.

±32

Flexible Data Types

Decode values as integers and floats with configurable byte and word ordering so you can match the real-world device layout you are looking at.

opt

Reliable Acquisition

Keep logging stable even when a device or data range acts up. Automatic read optimization and fault handling help preserve the rest of the signal set.
