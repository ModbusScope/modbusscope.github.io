ModbusScope

Visual Modbus Data Logging

Desktop application for real-time logging and visualization of Modbus TCP and RTU data. The visualization core is open-source under GPLv3. Built for industrial engineers, energy professionals, and embedded developers. Supports all register types, 16-bit/32-bit/float data types, combined reads, and exception splitting.
